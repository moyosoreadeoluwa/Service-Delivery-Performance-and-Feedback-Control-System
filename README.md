Service Delivery Performance and Feedback Control System

Project Overview

This project analyses customer service ticket data to evaluate service delivery performance, SLA compliance, response and resolution times, and customer feedback.

The analysis was designed to identify performance gaps and provide actionable insights that can help improve support efficiency and customer experience.

Dataset

* Total tickets: 2,330
* Within SLA: 1,547 (66.39%)
* SLA violations: 783 (33.61%)
* First response within SLA: 86.66%
* Average first response time: 38 minutes 43 seconds
* Average resolution time: 12 hours 45 minutes 44 seconds
* Average customer survey score: 3.75/5

Tools Used

* Microsoft Excel
* Power Query
* Power BI
* Data analysis and visualization

Key Findings

* 66.39% of tickets were resolved within the expected SLA, while 33.61% exceeded the SLA.
* First-response performance was considerably stronger, with 86.66% of tickets receiving a response within the expected timeframe.
* Tier 2 achieved a higher SLA compliance rate than Tier 1.
* The analysis highlights opportunities to improve resolution efficiency and reduce SLA violations.
* Customer feedback was analysed alongside operational performance to identify areas where service delivery could be improved.

Recommendations

1. Investigate the main causes of SLA violations.
2. Monitor resolution times more closely across support tiers.
3. Identify recurring ticket categories associated with longer resolution times.
4. Use customer feedback to identify service-quality issues.
5. Establish regular performance monitoring using dashboards and key performance indicators.
